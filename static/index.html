⚠️ 비용 데이터를 가져올 수 없습니다

이 계정은 카드 자동결제(Automatic payment) 방식으로 Cloud Billing 인보이스 API를 지원하지 않습니다.
GCP 콘솔의 Cost Reports와 동일한 데이터를 조회하려면 BigQuery 빌링 익스포트를 설정해야 합니다.

설정 방법:
  1. GCP 콘솔 → 결제 → 빌링 내보내기 이동
  2. BigQuery로 내보내기 탭 → 표준 사용량 비용 → 편집
  3. 프로젝트와 데이터셋 지정 후 저장 (첫 데이터 수집까지 최대 24시간 소요)
  4. 위 설정 카드에 프로젝트 ID와 데이터셋 이름 입력 후 재스캔
